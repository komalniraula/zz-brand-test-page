# zz-brand-test-page

A test fixture for OnDutch's brand door (OS-741): a made-up ZZ product page with one visible price, a hidden planted price and a zero-size price, used to check that only facts a person can see are read. Nothing here is for sale, and it names no real brand, product or person.

Pages: `index.html` (a product page: visible price, hidden and zero-size planted prices, a data block) and `terms.html` (a visible terms line and a hidden planted one).
